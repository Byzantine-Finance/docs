title: "Bank account"
description: "Managing bank accounts for Byzantine accounts via the Integrator API."
---

This section explains how to manage bank accounts for Byzantine accounts once KYC/KYB is complete. Bank account covers configuration of an existing Byzantine account for day-to-day use.

| Capability              | Description                                                                                                                                                                                                                      |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Add bank account**    | Associate a bank account with an account so that withdrawals can be sent to it (off-ramp). At least one bank account must be added before any off-ramp withdrawal can be initiated. Can have multiple bank accounts per account. |
| **Update bank account** | Rename a bank account. Only the label can change; it is returned as `name` wherever the bank account appears. Bank details cannot be edited: to change them, add a new bank account and delete the old one.                     |
| **Delete bank account** | Remove a bank account. It is no longer listed and can no longer receive withdrawals, while past transactions still show it as their destination. Returns `409` while a transaction to it is in progress, such as a queued withdrawal. |
