## Quick start

<Steps>
  <Step title="Install the skills">
    ```bash
    npx skills add Byzantine-Finance/agent-skills
    ```
  </Step>
  <Step title="Add the docs MCP server">
    ```bash
    claude mcp add --transport http byzantine-docs https://docs.byzantine.fi/mcp
    ```
  </Step>
  <Step title="Ask your agent">
    > "Integrate Byzantine in my app. Start with the sandbox: create an individual account, then a deposit."

    Your agent follows the [Integration guide](/api-reference/integration-guide) and the skills.
  </Step>
</Steps>

## Docs MCP server

`https://docs.byzantine.fi/mcp` lets your agent search these docs. It can look things up; it cannot create accounts or move funds.

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http byzantine-docs https://docs.byzantine.fi/mcp
    ```
  </Tab>
  <Tab title="Codex">
    ```bash
    codex mcp add byzantine-docs --url https://docs.byzantine.fi/mcp
    ```
  </Tab>
  <Tab title="Gemini CLI">
    ```bash
    gemini mcp add -t http byzantine-docs https://docs.byzantine.fi/mcp
    ```
  </Tab>
  <Tab title="Cursor">
    Add to `.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "byzantine-docs": { "url": "https://docs.byzantine.fi/mcp" }
      }
    }
    ```
  </Tab>
  <Tab title="VS Code">
    Add to `.vscode/mcp.json`:

    ```json
    {
      "servers": {
        "byzantine-docs": { "type": "http", "url": "https://docs.byzantine.fi/mcp" }
      }
    }
    ```
  </Tab>
</Tabs>

## Safe defaults

<CardGroup cols={2}>
  <Card title="Sandbox first" icon="flask">
    Build in the [sandbox](/api-reference/sandbox). The bundled scripts only call sandbox and dev, never production.
  </Card>

  <Card title="Keep keys out of chats" icon="lock">
    If a private key was pasted into a conversation, revoke it in the [integrator dashboard](https://integrator.byzantine.fi) (Settings → API keys) and create a new one.
  </Card>

  <Card title="Read-only keys for reporting" icon="eye">
    Use a `read_only` key for dashboards, reporting and support tools.
  </Card>

  <Card title="Funds stay under user control" icon="fingerprint">
    Your agent cannot move funds on its own: every deposit and withdrawal needs the user's passkey. See the [Integration guide](/api-reference/integration-guide).
  </Card>
</CardGroup>
