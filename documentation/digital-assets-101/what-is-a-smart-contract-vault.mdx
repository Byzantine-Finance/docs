# Clear rules. Automatic execution.

An automated contract is software that follows predefined rules. For Byzantine Prime, those rules route funds, track positions and returns, and process withdrawal requests.

## Who does what

- **Keyrock Curation Services:** Sets the strategy parameters
- **Byzantine:** Provides the interface and technical infrastructure
- **The automated contract:** Executes instructions within the approved rules
- **You:** Authorise activity and withdrawal requests

Byzantine does not hold client assets. The contracts and adapters developed for Byzantine are reviewed by independent security teams.
