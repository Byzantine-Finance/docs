# Protection, built in layers

No single control does all the work. Byzantine Prime combines several complementary mechanisms.

- **Predefined rules:** Funds can follow only approved parameters
- **Independent reviews:** Code is examined before launch
- **Continuous monitoring:** Hypernative monitors activity and flags unusual behaviour
- **Research programmes:** Independent researchers can report vulnerabilities
- **Controlled changes:** Material updates require a new review
- **Optional coverage:** Available for specified technical events, subject to terms

Byzantine provides technical infrastructure and does not hold client assets.
