# Clear controls at every step

Each material risk is matched with a defined control and a clear owner.

| Area | Primary control |
| --- | --- |
| **Strategy** | Predefined parameters and monitoring by Keyrock Curation Services |
| **Borrowers** | Collateral worth more than the amount borrowed |
| **Code** | Independent reviews before launch and after material changes |
| **Liquidity** | Continuous monitoring and allocation adjustments |
| **Custody** | Supported institutional custody or self-custody |
| **Operations** | Separation of roles and explicit user authorisation |

No framework removes every risk. The goal is to identify, limit and monitor risk continuously.
