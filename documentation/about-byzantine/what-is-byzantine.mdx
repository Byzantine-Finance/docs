# Make more of your cash

Byzantine Prime is technical infrastructure that helps companies and individuals access return opportunities on EUR and USD balances - with clear reporting, flexible access and regulated partners where required.

## Built for modern treasury

- Put EUR or USD balances to work
- Track performance and activity in one place
- Request withdrawals at any time
- Choose supported institutional custody or self-custody

Strategy curation is provided by Keyrock Curation Services. Byzantine never holds client assets.

Financial advisers can share factual information about Byzantine and introduce eligible clients.

<Note>
  Byzantine provides technical infrastructure. Returns are variable and not guaranteed.
</Note>
