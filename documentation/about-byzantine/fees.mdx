# One simple fee

Byzantine receives 10% of returns. If no return is generated, Byzantine does not receive a performance fee.

## Included

- Byzantine technical infrastructure and operations
- Strategy curation by Keyrock Curation Services
- Supported custody costs
- Strategy rebalancing

There is no management fee, entry fee or exit fee. Returns shown in the dashboard are net of Byzantine's fee.

<Note>
  Payment or conversion partners may apply separate charges where relevant.
</Note>
