# Everything important, at a glance

|  | Byzantine Prime |
| --- | --- |
| **Supported currencies** | EUR and USD |
| **Returns** | Variable and generated by third-party lending activity |
| **Access** | Withdrawal requests at any time, subject to liquidity and partner processing |
| **Strategy** | Curated and monitored by Keyrock |
| **Custody** | Supported institutional custody or self-custody |
| **Reporting** | Balance, performance and activity in one dashboard |
| **Fees** | 10% of returns, with no management, entry or exit fee |
| **Optional protection** | Available for specified technical risks, subject to terms and exclusions |

Returns come from borrower interest. Byzantine provides the technical infrastructure and does not hold client assets.

## Reading performance data

Vault APYs annualize past price-per-share changes over trailing windows. They are not guaranteed future returns. The public [performance API](/api-reference/vault-performance) includes snapshot timestamps and sampled history so integrators can distinguish an observed rate from a forecast or account-specific earnings.

<Note>
  Returns are variable and not guaranteed. Capital is at risk.
</Note>
