# Sachez toujours ce qui vient ensuite

| Transfert | Délai habituel |
| --- | --- |
| **EUR - SEPA instantané** | Généralement moins de 30 secondes |
| **EUR - SEPA standard** | 1-3 jours ouvrés |
| **USD - ACH le jour même** | Le même jour ouvré si le transfert est envoyé avant l'heure limite applicable |
| **USD - ACH standard** | 1-3 jours ouvrés |
| **USD - Virement bancaire** | Généralement sous 2 heures avant l'heure limite, sinon le jour ouvré suivant |
| **Transfert direct compatible** | Généralement moins de 30 secondes |

Pour un retrait bancaire, ajoutez le délai du réseau de paiement après la sortie des fonds de la stratégie.

Ces délais sont indicatifs et peuvent varier selon la banque, le partenaire de paiement, la liquidité du marché et les contrôles de conformité.
