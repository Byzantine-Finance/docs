# Revues indépendantes, avant mise en service

Les contrats et adaptateurs développés pour Byzantine ont été examinés par huit équipes de sécurité indépendantes. Les constats critiques et élevés identifiés pendant les tests ont été corrigés puis vérifiés avant la mise en service.

## Ce qui est vérifié

- Les droits d'accès et les autorisations
- Les calculs, règles d'allocation et demandes de retrait
- Les interactions avec les services externes
- Les scénarios connus d'exploitation du code
- Les procédures de modification et de déploiement

Les rapports d'audit sont disponibles pour consultation.

Keyrock Curation Services dispose également d'un rapport SOC 2 Type II sur ses contrôles opérationnels. L'émetteur des unités liées à l'EUR et à l'USD publie régulièrement des attestations sur les réserves.
